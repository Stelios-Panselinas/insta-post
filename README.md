# **Τεκμηρίωση Εφαρμογής Διαχείρισης Προσφορών**
Αυτό το έγγραφο παρέχει όλες τις λεπτομέρειες γύρω από τη λειτουργικότητα, την αρχιτεκτονική και την υλοποίηση της Εφαρμογής Διαχείρισης Προσφορών.
## **Επισκόπηση**
Η Εφαρμογή Διαχείρισης Προσφορών προβάλλει δυναμικά προσφορές από συγκεκριμένο κατάστημα, επιτρέποντας στους χρήστες να αλληλεπιδρούν μαζί τους. Η εφαρμογή χρησιμοποιεί επικοινωνία AJAX για να υποστηρίξει τις εξής λειτουργίες:
- Προβολή διαθέσιμων προσφορών με λεπτομέρειες όπως το όνομα του προϊόντος, η τιμή, και η ημερομηνία καταχώρησης.
- Εκτέλεση ενεργειών Like/Dislike στις προσφορές.
- Δήλωση προϊόντων ως "Εξαντλημένα" ή "Διαθέσιμα".
- Οριστική διαγραφή προσφορών από το σύστημα.
- Δυναμική ενημέρωση του UI με τα πιο πρόσφατα δεδομένα.

Η εφαρμογή συνδέεται με το backend για τη λήψη και τροποποίηση των δεδομένων προσφορών.
## **Τεχνολογίες που Χρησιμοποιούνται**
- **Frontend**: HTML, CSS, JavaScript (AJAX, χειρισμός DOM)
- **Backend**: PHP
- **Επικοινωνία**: AJAX (XMLHttpRequest)

## **Κύρια Χαρακτηριστικά**
- **Προβολή Προσφορών**: Προβολή προσφορών από κατάστημα σε δυναμική λίστα με πλήρη στοιχεία (όνομα, τιμή, κατάσταση αποθέματος, κ.λπ.).
- **Ενέργειες Χρήστη**:
    - **Like/Dislike**: Οι χρήστες μπορούν να βαθμολογήσουν την κάθε προσφορά.
    - **Διαχείριση Αποθέματος**: Ετικέτες "Δεν υπάρχει απόθεμα" και "Ξανά σε απόθεμα".
    - **Διαγραφή Προσφοράς**: Μόνιμη διαγραφή συγκεκριμένων προσφορών.

- **Διασύνδεση Backend**: Ενημέρωση του backend για αλλαγές στην κατάσταση των προσφορών (π.χ., ενεργοποίηση/απενεργοποίηση).

## **Frontend – Λειτουργία**
### **Διαδικασία Κατά Φόρτωση**
1. Όταν η σελίδα φορτώσει, το `window.onload` συμβάν ενεργοποιείται και προωθεί ένα AJAX αίτημα για τη λήψη προσφορών μέσω της μεθόδου `getOffersFromCategory` στο backend.
2. Οι προσφορές που ανακτώνται εμφανίζονται στο UI σε μορφή καρτών προσφορών, περιλαμβάνοντας:
    - Όνομα προϊόντος
    - Τιμή
    - Ημερομηνία καταχώρισης
    - Κατάσταση αποθέματος
    - Αριθμός Likes/Dislikes
    - Πληροφορίες για τον χρήστη που πρόσθεσε την προσφορά.

### **Βασικές Μέθοδοι JavaScript**
- **rateOffers()**: Αυτή η συνάρτηση εκτελείται κατά τη φόρτωση της σελίδας. Στέλνει AJAX αίτημα για τη λήψη προσφορών και δημιουργεί δυναμικά το περιεχόμενο της σελίδας.

- **disableButtons(offer_id)**: Απενεργοποιεί όλα τα κουμπιά αλληλεπίδρασης για μια συγκεκριμένη προσφορά και ενημερώνει το backend ότι η προσφορά εξαντλήθηκε.

- **enableButtons(offer_id)**: Ενεργοποιεί εκ νέου τα κουμπιά για μια προσφορά που είχε χαρακτηριστεί ως εξαντλημένη.

- **deleteOffer(offer_id)**: Στέλνει αίτημα AJAX για τη διαγραφή μιας συγκεκριμένης προσφοράς από το backend.

## **Backend – Ολοκλήρωση**
Το backend διαχειρίζεται όλη την επιχειρηματική λογική και τις λειτουργίες της βάσης δεδομένων για τις προσφορές. Ακολουθούν οι βασικές μέθοδοι που πρέπει να υποστηρίζονται:
### **Απαιτούμενες Μέθοδοι Backend**
1. **`getOffersFromCategory`**
Παράδειγμα URL:
`../../classes/Shop.php?function=getOffersFromCategory&category_id=0&shop_id=<shop_id>`
**Περιγραφή**: Επιστρέφει JSON δεδομένα με τις διαθέσιμες προσφορές για μια συγκεκριμένη κατηγορία και κατάστημα.
2. **`disableOffer`**
Παράδειγμα URL:
`../../classes/Shop.php?function=disableOffer&offer_id=<offer_id>`
**Περιγραφή**: Ενημερώνει την προσφορά ώστε να χαρακτηρισθεί ως "Εξαντλημένη".
3. **`deleteOffer`**
Παράδειγμα URL:
`../../classes/Shop.php?function=deleteOffer&offer_id=<offer_id>`
**Περιγραφή**: Δίνει εντολή για τη διαγραφή μιας προσφοράς από τη βάση δεδομένων.
